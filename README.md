# Vistula Task Manager

Simple Task Manager built with HTML, CSS and JavaScript, using the Supabase REST API as its database.
Created for Practical Assignment 1 – Team Project IT.

**Student ID:** 72608

## Features

- Display all tasks
- Add, edit and delete tasks
- Mark tasks as completed / incomplete
- All data stored in Supabase (persists after refresh)

## Technologies

- HTML, CSS, JavaScript (no framework)
- Supabase (PostgreSQL) + auto-generated REST API
- GitHub Pages hosting
